## Hvad blev bygget

Fase B-fundamentet (SPEC Tillæg B + §9-princippet) som rent additivt
bibliotek — ingen UI, ingen API-kald, alt deterministisk og testet mod mocks:

- `lib/video/provider.ts` — det fulde `VideoProvider`-interface med async
  jobmodel (`indsendJob`/`hentStatus`/`hentResultat`) plus webhook-payload-
  typer (`VideoWebhookPayload`, diskrimineret på `udfald`). Spejlet efter
  `ImageProvider`-mønstret i `lib/providers/image.ts` (dansk navngivning,
  `costDkk`, provider bag interface jf. C-7/NFR-5).
- `lib/video/mock.ts` — `MockVideoProvider` med deterministiske fixtures:
  tæller-baserede job-id'er (`mock-video-job-1`…), fast pris-formel
  (`mockKlipPrisDkk` = 0,50 kr./sek.), konfigurerbar fejlvej og antal
  statuskald før færdig, samt `webhookPayload()` som fixture til kommende
  webhook-tests. Ingen `Date.now`/`Math.random`.
- `lib/video/prompt-compiler.ts` — 8-bloks UGC-promptsystemet som typet,
  deterministisk compiler: (1) stil-anker, (2) karakter-anker, (3) lokation,
  (4) action beats, (5) dialog med ordgrænse pr. varighed, (6) audio-instruks,
  (7) fast negativ-liste (kan kun udvides, aldrig erstattes), (8) teknik.
  Output er versioneret (`promptVersion`, jf. FR-15-princippet).
- `lib/video/script-types.ts` — typer for brief → scripts:
  `VideoBrief`, `UgcScript` (hook/beats/CTA), `ScriptBeat` (handling/replik).
- `tests/unit/video-prompt-compiler.test.ts` + `tests/unit/video-provider.test.ts`
  — 30 nye tests (i alt 115 grønne).

## Forholdet til S3-stubben i `lib/providers/video.ts`

S3-stubben (`VideoKlipInput`/`VideoKlipResultat`/`VideoProvider.genererKlip`,
H-1) er bevidst URØRT — den importeres af `lib/providers/mock.ts` og
`lib/providers/index.ts` og testes i `tests/unit/providers.test.ts`.
Den komplette fase B-version bor i `lib/video/` og afløser stubben, når
videopipelinen implementeres: stubbens synkrone `genererKlip` kan ikke bære
Seedance-virkeligheden (minutter-lange jobs → submit/status/webhook), så
`lib/video/provider.ts` er interfacet, fal-adapteren skal implementere.
Migrationen (slet stub, flyt imports) er et selvstændigt fase B-arbejde og
hører ikke hjemme i denne rent additive PR.

## Beslutninger truffet undervejs

- **Ordgrænse:** 2 ord/sekund (`ORD_PR_SEKUND`) som loft for lipsynket dansk
  UGC-dialog; håndhævet med fejl (ikke trunkering), så scriptlaget tvinges til
  at skrive kortere — compileren "reparerer" aldrig stiltiende. Kalibreres mod
  rigtige Seedance-kørsler, når fase B starter (danske tale-eksperiment,
  Tillæg B).
- **Varighed:** hele sekunder 4–15 (Seedance 2.0-spændet, Tillæg B) —
  compileren afviser alt andet.
- **Referencer:** nummereres `@image1…` i inputrækkefølge (som Seedance
  forventer) og bindes til blokke via rolle (karakter/produkt/lokation);
  første reference pr. rolle bruges. Teknik-blokken bærer et eksplicit
  manifest (`Referencer: @image1 = karakter, …`), så nummereringen er
  synlig og testbar.
- **Negativ-liste:** `FAST_NEGATIV_LISTE` er altid med og kan kun udvides
  (`ekstraNegativer`) — samme håndhævelses-princip som D-2/C-4 (kodet, ikke
  vejledt).
- **Dialog er påkrævet:** UGC-klippene bæres af tale; rene b-roll-klip uden
  dialog er et fase B-behov, der kan tilføjes som eksplicit variant senere.
- **Mock-navnesammenfald:** `MockVideoProvider` findes både i
  `lib/providers/mock.ts` (stub, kaster "fase B") og `lib/video/mock.ts`
  (fuld). Accepteret, fordi stubben forsvinder ved migrationen; indtil da
  skelner import-stien.
