# Session 2026-08-15 — transaktionsmails som kode (feat/emails)

## Hvad
Alle transaktionsmails bygget som kode, klar til Resend når nøglerne findes
(HANDOFF §6.6). Intet er koblet ind i app-flowet — afsendelse er en senere
integrationsopgave.

- `/emails/` (ny mappe, repo-roden): fem skabeloner som React-komponenter med
  tabel-layout og inline styles (mail-kompatibel HTML, ingen Tailwind):
  - `magic-link.tsx` (A-1)
  - `velkomst.tsx` — lover IKKE gratis annoncer (gratis-tier afskaffet, STATUS 2026-08-15)
  - `annonce-klar.tsx` (B-5)
  - `kvittering.tsx` — supplement til Stripes kvittering (E-2/E-6)
  - `kredit-refunderet.tsx` — delvis leverance (B-6)
  - `komponenter.tsx` (ramme/knap/flade/trinliste), `stil.ts` (e-mail-safe
    værdier AFLEDT af `lib/design/tokens.ts` — rgba→fast blandfarve, rem→px,
    webfont-roller→systemstakke), `render.tsx` (skabelon → komplet HTML-dokument)
- `lib/copy/emails.ts` (ny): al mail-copy, manifest-dansk (HANDOFF §2.2.4);
  eksisterende copy-filer urørt
- `lib/emails/send.ts` (ny): `EmailAfsender`-interface + `MockEmailAfsender` +
  `ResendEmailAfsender` bag `hentEmailAfsender()` — samme mønster som
  `lib/providers` (mock uden nøgle / med `MOCK_PROVIDERS=1`)
- `app/dev/emails/page.tsx` (ny dev-route): renderer alle skabeloner med
  eksempeldata; `notFound()` i production
- `.env.example`: `RESEND_FROM` dokumenteret (ingen værdier)
- `vitest.config.ts`: `esbuild: { jsx: "automatic" }` så .tsx-tests kan køre
  (tsconfig har `jsx: "preserve"`, som Next selv transformerer)

## Tests
35 nye (120 i alt, alle grønne):
- `tests/unit/emails.test.tsx`: alle 5 skabeloner renderer uden fejl til
  komplet HTML med indhold/links/footer/preheader; tabeller + inline styles og
  INGEN `class=`-attributter; mock-afsenderen registrerer beskeder;
  `hentEmailAfsender` vælger mock uden nøgle og med `MOCK_PROVIDERS=1`
- `tests/unit/emails-copy.test.ts`: manifest-reglerne (forbudte ord, emojis)
  håndhævet på `lib/copy/emails.ts` efter mønstret fra `copy.test.ts` (urørt);
  plus værn mod løfter om gratis annoncer

## Verificeret
- `npm run typecheck` + `npm run lint` + `npm test` grønne (inkl. alle 85
  eksisterende tests)
- `/dev/emails` gennemgået visuelt i browser på port 3005: kalk-baggrund,
  hairlines, gran-knapper (44 px touch-mål), hør-flade med mono-købslinje,
  dæmpede noter — v6-udtrykket oversat til mail
- Production-build + `next start`: `/dev/emails` svarer 404

## Bevidste valg
- Mail-HTML bygget i hånden (tabeller/inline styles) — ingen react-email eller
  andre nye dependencies (opgavekrav; `resend` var allerede i package.json)
- Skrifter i mails er systemstakke (Arial/Courier New): mail-klienter loader
  ikke self-hostede webfonts; rollerne fra tokens er spejlet, ikke erstattet
- `roller.kant` er rgba og falder ud i ældre Outlook → hairline/dæmpet farve
  beregnes som faste blandinger af koks/kalk i `emails/stil.ts`
- Dev-siden renderer skabelonerne som JSX direkte (ikke via `render.tsx`), så
  `react-dom/server` aldrig importeres i en Server Component
