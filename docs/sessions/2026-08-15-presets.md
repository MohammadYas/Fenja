# Session 2026-08-15 · Preset-system klar til Gate 1 (branch `feat/preset-system`)

Parallel-session i eget worktree; STATUS.md/BACKLOG.md er bevidst IKKE rørt
(andre sessioner arbejder på `samlet` samtidig — dette notat er sessionens log).

## Hvad blev bygget

1. **`lib/pipeline/presets/` (mappe, tidligere én fil `presets.ts`)**
   - `typer.ts`: `Preset` + `PromptBlokke` — hvert preset er et typet,
     versioneret objekt der bærer alle 5 promptblokke fra SPEC §9
     (reference-instruks, person-ankre m. rotation, nordisk setting, fotostil,
     negativ-liste).
   - `definitioner.ts`: de 3 launch-presets (lys minimalisme, københavnsk gade,
     hyggelig stue) — kun setting-blokken varierer; fælles blokke bæres af
     hvert preset, så én (id, version) beskriver hele sin prompt.
   - `kompiler.ts`: deterministisk kompilering (ingen Math.random/Date.now);
     person-rammen ("anonym, aldrig genkendelig", C-6) er hardcodet i
     kompileren og kan ikke redigeres pr. preset; tom/blank negativ-liste
     afvises med fejl. `presetVersionsTag()` matcher `generations.prompt_version`.
   - `stats.ts`: `PresetStatsStore`-interface + `MockPresetStatsStore`
     (in-memory, samme inkrementelle gennemsnit som DB-funktionen) +
     `SupabasePresetStatsStore` (rpc `registrer_preset_koersel`).
   - `index.ts`: offentlig API — **uændret** ift. gamle `presets.ts`
     (`Preset`, `PRESETS`, `STANDARD_PRESET_ID`, `hentPreset`,
     `vaelgPersonAnker`, `bygOnModelPrompt`) + tilføjelserne. Prompt-outputtet
     er byte-identisk med før; `onmodel.ts` er urørt.

2. **Migration `20260815020000_preset_stats.sql`**: tabel `preset_stats`
   (preset_id text, version, runs, passes, avg_fidelity, updated_at; PK
   (preset_id, version)); RLS med læs-for-alle (aggregat, ikke persondata);
   skrivning kun via security definer-funktionen `registrer_preset_koersel`
   med `revoke execute` for anon/authenticated (NFR-6). `preset_id` er
   kode-presettets slug — bevidst ingen FK til uuid-tabellen `public.presets`.

3. **`scripts/gate1-fidelity-test.ts`** (fandtes ikke før — scripts/ var tom):
   - `npx tsx scripts/gate1-fidelity-test.ts <mappe-med-toejfotos> [--live] [--ud sti.html]`
   - Kører hvert foto gennem alle 3 presets × 2 reference-styrker
     (`normalReferenceVaegt`/`strammereReferenceVaegt` fra config) via
     `ImageProvider`; mock er default med deterministiske scores (hash, ingen
     tilfældighed). `--live` bruger fal + Anthropic og kræver nøgler (IKKE
     kørt i denne session); lokale filer sendes som data-URL i live-tilstand.
   - Scores registreres i `preset_stats` via `PresetStatsStore` (mock som
     default; Supabase-storen bruges kun med `--live` + Supabase-env).
   - Skriver en side-om-side-HTML-rapport (reference vs. 6 genereringer pr.
     foto) med manuel OK/Ikke OK-scoring pr. billede, note-felt, live
     pass-rate-beregning pr. preset og Gate 1-dom (≥ 70 % for mindst ét
     preset), plus de fuldt kompilerede prompts. Rapporten er en lokal fil —
     committes ikke.

4. **Tests `tests/unit/presets.test.ts`** (11 nye; 96 i alt, alle grønne):
   determinisme (inkl. at kompileringen fejler højlydt hvis Math.random/
   Date.now patches til at kaste), rotation når alle ankre (C-6), negativ-
   listen kan aldrig udelades (tom/blank liste kaster), mock-statsstorens
   aggregering, versions-tag-format.
